Chatbot API

A chatbot API with a Streamlit client interface.

Getting Started
1. Start the Backend Service

Run the backend service using:

python main.py

2. Start the Streamlit Client

In a separate terminal, run the Streamlit application:

streamlit run client.py


The Streamlit application will open in your browser.

Project Structure
chatbot-api/
├── main.py       # Backend service
├── client.py     # Streamlit client
└── README.md     # Project documentation

Requirements

Make sure Python and the required project dependencies are installed before running the application.

If a requirements.txt file is available, install the dependencies with:

pip install -r requirements.txt
